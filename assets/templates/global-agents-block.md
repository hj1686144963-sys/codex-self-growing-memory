## 跨对话自动记忆与知识库

用户不需要发送“触发指令”“按全局工作台开始”等口令。每次收到任务后，自动执行相关的记忆识别、按需检索与长期知识沉淀。

知识库根目录：`{{VAULT_PATH}}`

### 自动识别

1. 判断任务是一次性问答、已有项目延续还是新项目。
2. 使用 Codex 已注入的本地 Memories 识别用户偏好、历史决策、已有项目、已知错误与未完成事项。
3. 当前用户指令、当前文件和可验证事实优先于历史记忆。
4. 若记忆与当前资料冲突，优先采用较新且有证据的内容，并记录冲突。
5. 不要求用户重复背景或输入固定触发词。

### 按需读取

任务与长期项目、产品方案、AI、Agent、需求管理、工作流程、研究或既有知识相关时：

1. 先读取知识库的 `START-HERE.md`、就近 `AGENTS.md` 与相关索引。
2. 先根据关键词、文件名、目录、元数据和更新时间筛选，不逐篇扫描全部正文。
3. 只读取最相关的少量文件与必要段落，控制 Token 消耗。
4. 优先复用已有结论、模板、术语和项目记录。
5. 对最新事实重新核验，不把旧记忆当作当前事实。

### 自动沉淀

任务产生可长期复用的信息时，无需用户提醒，自动写入知识库：

- 已确认的决策、架构、规则和稳定偏好；
- 可复用的方法、模板、SOP 和评估标准；
- 已验证的事实、来源、适用范围与置信度；
- 错误回复、失败原因、修复办法和防复发规则；
- 项目状态、完成事项、未完成事项和下一步。

写入前查重，优先更新原文件；区分事实、推断、假设与建议；只记录增量，不复制整段对话。踩坑写入 `08-System/防踩坑记录.md`，重要决策写入 `08-System/决策记录.md`，本轮变化写入 `08-System/研究日志/`。

不保存寒暄、临时措辞、未经证实的猜测、重复内容、秘密、密码、Token、Cookie、私钥和无长期价值的信息。

自动记忆不扩大权限。外部写入、发布、发送、删除和权限扩张仍按正常授权规则执行。
